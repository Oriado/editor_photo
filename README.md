# Редактор фото

Десктопний редактор фотографій на Python з графічним інтерфейсом (tkinter) та обробкою зображень через OpenCV.

## Можливості

### Кнопки-фільтри
| Кнопка | Опис |
|---|---|
| Чорно-біле | Перетворює фото у відтінки сірого |
| Дзеркало | Горизонтальне відображення |
| Поворот | Поворот на 90° за годинниковою стрілкою |
| Негатив | Інверсія кольорів |
| Малюнок | Ефект олівцевого ескізу |
| Розмиття | Gaussian Blur |
| Пікселі | Піксель-арт ефект |
| Виявлення країв | Алгоритм Canny |
| Акварель | Ефект акварельного малюнка |
| Метал | Ефект тиснення (emboss) |
| Різкість | Підвищення різкості |

### Слайдери
| Слайдер | Діапазон | Опис |
|---|---|---|
| Яскравість | -50 … +50 | Зміна яскравості |
| Розмір вертикалі | 100 … 1080 | Висота зображення (px) |
| Розмір горизонталі | 100 … 1920 | Ширина зображення (px) |
| Контраст | 0.1 … 3.0 | Коефіцієнт контрасту |
| Сепія | 0.0 … 1.0 | Інтенсивність ефекту сепії |
| Теплий відтінок | 0 … 50 | Додає теплоти (підсилює червоний) |
| Холодний відтінок | 0 … 50 | Додає холодності (підсилює синій) |
| Шум | 0 … 100 | Рівень випадкового шуму |
| Пастеризація | 1 … 64 | Кількість рівнів кольору |
| Вінетка | 0.1 … 1.0 | Затемнення країв |

## Технології

- **Python 3**
- **tkinter** — графічний інтерфейс
- **OpenCV (cv2)** — обробка зображень
- **NumPy** — операції з масивами пікселів
- **Pillow (PIL)** — відображення зображень у tkinter

## Встановлення

```bash
pip install opencv-python numpy Pillow
```

## Запуск

```bash
python main.py
```

## Структура проєкту

```
editor_photo/
├── main.py        # Головний файл: вікно, кнопки, слайдери
├── interface.py   # Обробники подій GUI
└── editor.py      # Функції обробки зображень (OpenCV)
```

## Використання

1. Натисніть **Відкрити фото** та оберіть файл
2. Застосовуйте фільтри кнопками або налаштовуйте слайдери
3. **Скинути фільтри** повертає оригінальне зображення
4. **Зберегти фото** — зберігає результат у форматі JPG або PNG
